# 🧹 Slime Imbiber

> 청소기 하나로 슬라임 세계를 빨아들이는 세로형 2D 액션 서바이벌 게임

Unity로 만드는 네 번째 2D 게임입니다.
청소기를 멘 아이가 끝없이 몰려오는 슬라임을 빨아들이며 다섯 개의 지역을 지나 슬라임의 근원을 찾아가는, **엔딩이 있는 완결형 모바일 게임**을 목표로 하고 있습니다.

- **장르**: 로그라이트 액션 서바이벌 (뱀파이어 서바이벌류)
- **플랫폼**: Android (Google Play 무료 출시 예정)
- **화면**: 세로 모드, 한 손 조이스틱 조작
- **광고·유료 결제 없음**

---

## 🎮 게임 소개

조이스틱으로 움직이면 청소기가 앞쪽의 슬라임을 자동으로 빨아들입니다.
판마다 레벨업으로 스킬을 골라 조합을 만들고, 5분을 버틴 뒤 나타나는 보스를 쓰러뜨리면 스테이지 클리어!
판이 끝나면 모은 **젤**로 실험실 잼통을 채워 캐릭터를 영구히 강하게 만듭니다.

### 스테이지와 보스

| 스테이지 | 지역 | 보스 |
|---|---|---|
| 1 | 슬라임 초원 (Slime Meadow) | 킹 슬라임 |
| 2 | 버섯 숲 (Mushroom Grove) | 머쉬룸 킹 |
| 3 | 모래 사막 (Sand Dunes) | 샌드웜 |
| 4 | 얼음 골짜기 (Frost Valley) | 프로스트 퀸 |
| 5 | 화산 동굴 (Magma Cave) | 마그마 골렘 |

각 스테이지에는 지역만의 특수 슬라임과 보스 패턴이 있고, 클리어 후에는 더 강한 적이 나오는 **하드 모드**가 열립니다.

## ✨ 주요 기능

### ⚔️ 전투
- 흡입, 불, 얼음, 번개, 폭탄 등 다양한 스킬을 레벨업으로 골라 조합
- 스킬 카드 강화와 **각성**으로 더 강력한 형태로 진화
- 보스마다 고유 패턴과 공격 예고 연출

### 🧪 성장
- **실험실**: 슬라임 젤로 잼통을 채워 공격력, 체력, 이동 속도 등 영구 능력치 상승
- **보스 잼통**: 보스 젤로 강력한 보너스와 보스 전용 스킬 해금
- **전투력** 표시로 성장을 한눈에 확인

### 👕 스킨과 테마
- 캐릭터 스킨 뽑기와 젬 직접 구매
- 전설 스킨 **홍길동**, **유령 소환사**와 각 스킨 전용 스킬 3종 (분신술, 유령 친구, 공중부양 등)
- 메뉴 전체 분위기를 바꾸는 테마 (조선, 영혼 등불 등)

### 🏰 엔딩 후 콘텐츠
- **레이드**: 체력 바 여러 줄짜리 거대 보스를 5분 안에 쓰러뜨리는 도전 (EASY / NORMAL / HARD)
  - 🦊 **구미호**: 분신 돌진, 매혹, 꼬리 공격, 그리고 모두 타 버리면 즉사하는 부적 4장
  - 🏮 **등불 저승사자**: 영혼 등불 보호막, 어둠, 유령 행렬, 영혼 사슬
- **골드 던전 / 젬 던전**: 재화를 모으는 단계별 도전
- **슬라임 광산**: 잡은 슬라임이 젬을 캐 주는 방치형 콘텐츠
- **도감**: 만난 슬라임과 보스 기록
